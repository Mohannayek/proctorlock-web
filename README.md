# ProctorLock Web Client 🔒

![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)
![Status](https://img.shields.io/badge/status-active-success.svg)

**ProctorLock Web** is the dedicated browser-based frontend for a secure, AI-powered examination platform. Designed to modernize digital assessments, this interface provides a highly responsive and frictionless experience for both administrators configuring tests and examinees taking them.

This repository houses the web portal, which works in tandem with the [ProctorLock Android app] and the serverless AWS backend.

## ✨ Key Features

* **Role-Based Portals:** Dedicated interfaces for Examinees (test-taking environment) and Administrators (exam creation and monitoring).
* **AI-Proctoring Integration:** Connects with backend AI services for real-time monitoring and anomaly detection during assessments.
* **Figma-Driven UI/UX:** A clean, intuitive layout meticulously translated from custom Figma designs to minimize user friction during high-stakes exams.
* **Real-Time Synchronization:** Seamless API communication with the AWS serverless backend ensures exam states and timers are perfectly synced.
* **Cross-Platform Synergy:** Operates alongside the ProctorLock Android application for a unified testing environment.
